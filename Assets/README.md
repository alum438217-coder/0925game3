# 0925game3

這是一個使用 Unity 製作的簡單輪盤遊戲原型，核心功能是：點擊滑鼠後讓輪盤開始旋轉，並隨時間逐漸減速，形成類似抽獎或轉盤效果的動畫。

## 專案簡介

- 遊戲類型：2D 互動原型
- 引擎：Unity 6000.3.25f1
- 主要腳本：`RouletteController`
- 主要內容：輪盤旋轉、點擊觸發轉動、逐步減速

## 遊戲玩法

1. 啟動專案後，打開 `SampleScene`。
2. 點擊滑鼠左鍵或觸控螢幕。
3. 輪盤會開始轉動。
4. 旋轉速度會逐漸衰減，直到停下來。

## 專案結構

- `Assets/Scenes/SampleScene.unity`：遊戲場景
- `Assets/RouletteController.cs`：輪盤旋轉控制腳本
- `Assets/README.md`：專案說明文件

## 主要程式邏輯

`RouletteController` 會在每一幀更新輪盤角度：

- 點擊滑鼠時設定初始旋轉速度
- 使用 `transform.Rotate()` 讓物件持續轉動
- 每幀乘上一個衰減係數 `0.96f`，使輪盤逐漸停止
- 將 `Application.targetFrameRate = 60;` 設為 60 FPS，讓動畫更順暢

## 執行方式

1. 安裝 Unity 6000.3.25f1 或相容版本。
2. 打開此專案資料夾作為 Unity 專案。
3. 在 Unity Editor 中載入 `Assets/Scenes/SampleScene.unity`。
4. 按下播放鍵即可測試。
